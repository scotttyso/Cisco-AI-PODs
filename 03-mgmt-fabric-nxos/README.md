# Subsystem 03 - Management fabric (NX-OS / Nexus Dashboard)

Stub. Will onboard the out-of-band management network switches (CIMC/BMC, ND
management, switch mgmt0, and deployment-server access) into Nexus Dashboard
from the ND cluster built in Subsystem 01, as a fabric separate from the
backend (02) and frontend (03) fabrics.

The bootstrap DHCP scope generated by
[00-environment-prep](../00-environment-prep/README.md) runs on this network,
so this fabric should be in place before device registration (05/06).

Schema: [`schemas/mgmt-fabric-nxos.schema.json`](../schemas/mgmt-fabric-nxos.schema.json) (stub today).
